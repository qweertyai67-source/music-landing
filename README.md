# Artist Site Studio

Статический коммерческий лендинг для создания сайтов артистов и музыкальных лендингов.

## Локально

Откройте `index.html` в браузере или запустите любой статический сервер.

## Перед публикацией

Замените `TELEGRAM_URL` в нижнем блоке `index.html` на реальную ссылку Telegram-канала. Демонстрационные концепции можно заменить на реальные кейсы.

UTM-метки сохраняются в `sessionStorage` и добавляются к ссылке Telegram после подключения URL. Внешняя аналитика не подключена.
